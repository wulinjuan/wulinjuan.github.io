# Linjuan Wu — Personal homepage

纯静态学术主页，可直接部署到 GitHub Pages，无需安装依赖。

## 发布到 GitHub Pages

1. 登录 https://github.com/new ，创建公开仓库 **wulinjuan.github.io**。
2. 将本文件夹中的 `index.html`、`style.css`、`assets/` 和 `.nojekyll` 上传到仓库根目录。保留 assets 文件夹结构。
3. 在仓库 Settings → Pages → Build and deployment 中选择 **Deploy from a branch**，选择 **main** 和 **/(root)**，点击 Save。
4. 部署完成后访问 https://wulinjuan.github.io/ 。通常需要几分钟。

官方说明：https://docs.github.com/en/pages/quickstart
